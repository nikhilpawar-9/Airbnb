# Wanderlust

A full-stack accommodation booking web application inspired by Airbnb, built using Node.js, Express.js, MongoDB, Mongoose and EJS.

## Features

- User authentication and authorization
- User, Host and Admin roles
- Host request and admin approval system
- Create, edit and delete listings
- Search listings by destination
- Filter listings by country
- Sort listings by price
- Reviews and ratings
- Booking system with date availability
- Booking cancellation
- Maximum guest validation
- Host booking management
- Host listing management
- Admin host request management
- Responsive design for desktop and mobile

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- HTML
- CSS
- JavaScript
- Joi
- Express Session
- bcrypt
